# Metadata Quality Benchmarks
This is the Github repository for the DLF AIG Metadata Working Group’s live/production implementation of benchmarks for metadata quality developed by the DLF-AIG Metadata Working Group Benchmarks Sub-Group: https://dlfmetadataassessment.github.io/MetadataQualityBenchmarks/

## Providing Feedback on Benchmarks
To submit comments or suggestions, use the "Issues" button at the top of the page to send any feedback about the benchmarks and supplementary pages.  Please be specific so that we have enough context.  All issues will be discussed by the MWG when time permits; we may not accept all suggestions.

If you want to reference a specific page or statement (e.g., if you find a typo or text that you believe is unclear), you can click on the "doc" folder above to find the source page (it will have the same name as the end of the URL on the live site).  Switch to "code" view in the upper-left part of the window and highlight the line that you want to reference.  Three dots (...) should appear to the left of the line number; clicking on that will let you create an issue directly linked to the line you have highlighted.
